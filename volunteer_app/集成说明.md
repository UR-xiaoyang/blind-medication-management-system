## 待完成

### 高德地图集成
由于高德地图 SDK 需要 API Key 和原生配置，目前实现了：
- ✅ 创建地图 Provider（模拟数据）
- ✅ 创建地图界面 UI

**需要手动配置：**

1. **申请高德地图 Key**
   - 前往 [高德开放平台](https://lbs.amap.com/) 注册账号
   - 创建应用，获取 Android 和 iOS 的 Key
   - Android 包名：`com.example.volunteer_app`
   - iOS Bundle ID：`com.example.volunteerApp`

2. **添加依赖**
   ```yaml
   # pubspec.yaml
   dependencies:
     amap_flutter_map: ^3.0.0
     amap_flutter_location: ^3.0.0
   ```

3. **Android 配置** (`android/app/src/main/AndroidManifest.xml`)
   ```xml
   <meta-data
     android:name="com.amap.api.v2.apikey"
     android:value="YOUR_AMAP_KEY_HERE"/>
   <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
   <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
   <uses-permission android:name="android.permission.INTERNET"/>
   <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"/>
   ```

4. **iOS 配置** (`ios/Runner/AppDelegate.swift`)
   ```swift
   import AMapFoundationKit

   @UIApplicationMain
   class AppDelegate: FlutterAppDelegate {
     override func application(
       _ application: UIApplication,
       didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
     ) -> Bool {
       AMapServices.shared().apiKey = "YOUR_AMAP_KEY_HERE"
       return super.application(application, didFinishLaunchingWithOptions: launchOptions)
     }
   }
   ```

5. **更新代码**
   - 修改 `lib/features/location/screens/map_screen.dart`
   - 替换模拟地图为真实的 AMap Flutter

## API 接口说明

后端 API 基础配置（可在 `api_constants.dart` 中修改）：
```
开发环境: http://localhost:8080/api
测试环境: https://staging.your-domain.com/api
生产环境: https://your-production-domain.com/api
```

所有 API 都需要 JWT 认证，登录后会自动在 Header 中添加：
```
Authorization: Bearer <your-token>
```
