请根据以下步骤完成配置：

## 1. 配置 API 环境

编辑 `volunteer_app/lib/core/constants/api_constants.dart`：

```dart
// 当前环境 - 修改这里切换环境
static const String currentEnv = 'development'; // development, staging, production

// 获取当前环境的 Base URL
static String get baseUrl {
  switch (currentEnv) {
    case 'production':
      return _prodBaseUrl;
    case 'staging':
      return _stagingBaseUrl;
    case 'development':
    default:
      return _devBaseUrl;
  }
}
```

修改 `_devBaseUrl`、`_prodBaseUrl`、`_stagingBaseUrl` 为你的实际后端地址。

## 2. 生成 Riverpod 代码

在 volunteer_app 目录下运行：

```bash
# 安装依赖（如未安装）
flutter pub add riverpod_annotation dio flutter_riverpod go_router amap_flutter_map amap_flutter_location

# 开发依赖
flutter pub add dev:build_runner dev:riverpod_generator

# 运行代码生成
dart run build_runner build

# 或实时监听变化
dart run build_runner watch
```

## 3. 配置高德地图

### 申请 Key
1. 前往 https://lbs.amap.com/
2. 创建应用
3. 添加 Android 和 iOS 平台
4. 获取 API Key

### Android 配置

编辑 `volunteer_app/android/app/src/main/AndroidManifest.xml`：

在 `<application>` 标签内添加：
```xml
<meta-data
    android:name="com.amap.api.v2.apikey"
    android:value="YOUR_AMAP_ANDROID_KEY_HERE"/>
```

确保已添加权限：
```xml
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"/>
```

### iOS 配置

编辑 `volunteer_app/ios/Runner/AppDelegate.swift`：

```swift
import UIKit
import Flutter
import AMapFoundationKit

@UIApplicationMain
class AppDelegate: FlutterAppDelegate {
    override func application(
        _ application: UIApplication,
        didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
    ) -> Bool {
        // 配置高德地图 Key
        AMapServices.shared().apiKey = "YOUR_AMAP_IOS_KEY_HERE"
        
        GeneratedPluginRegistrant.register(with: self)
        return super.application(application, didFinishLaunchingWithOptions: launchOptions)
    }
}
```

## 4. 更新地图代码

编辑 `volunteer_app/lib/features/location/screens/map_screen.dart`，替换模拟地图为真实的 AMap：

```dart
import 'package:amap_flutter_map/amap_flutter_map.dart';

// 在 MapScreen 中
AMapWidget(
    initialCameraPosition: CameraPosition(
        target: LatLng(39.909187, 116.397451), // 北京天安门
        zoom: 15.0,
    ),
    // ... 其他配置
)
```

```bash
cd volunteer_app
flutter pub get
flutter run
```
